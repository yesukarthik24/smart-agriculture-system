# Smart Agriculture Monitoring System

## Overview
The Smart Agriculture Monitoring System is an IoT-based project designed to monitor soil moisture, temperature, and humidity levels in agricultural fields. The system helps farmers automate irrigation and improve water management using sensors and microcontrollers.

---

## Features
- Soil moisture monitoring
- Temperature and humidity monitoring
- Automatic irrigation control
- Real-time sensor data collection
- Water-saving automation

---

## Technologies Used
- Arduino UNO / ESP32
- Soil Moisture Sensor
- DHT11 Sensor
- Relay Module
- Embedded C / Arduino IDE

---

## Project Components
- Microcontroller
- Soil Moisture Sensor
- DHT11 Temperature & Humidity Sensor
- Water Pump
- Relay Module
- Power Supply

---

## Working Principle
The soil moisture sensor checks the moisture level in the soil. If the moisture level becomes low, the relay automatically turns ON the water pump for irrigation. Temperature and humidity values are also monitored using the DHT11 sensor.
