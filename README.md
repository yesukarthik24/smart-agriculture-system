# 🌾 Smart Agriculture System

## 📖 Overview

The Smart Agriculture System is an IoT-based project designed to monitor environmental conditions in agricultural fields. It collects real-time sensor data and helps improve farming efficiency through continuous monitoring.

---

## 🚀 Features

- Real-time environmental monitoring
- Temperature and humidity monitoring
- Wireless data transmission
- Cloud-based data storage
- IoT-enabled smart farming solution
- Low-cost and energy-efficient design

---

## ⚙️ Working

1. The DHT11 sensor collects temperature and humidity data.
2. Arduino processes the sensor readings.
3. ESP8266 sends the data over Wi-Fi.
4. Sensor data is stored and monitored using Firebase.
5. Users can monitor environmental conditions in real time.
